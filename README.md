# PvP HUD System

A customizable PvP HUD for FiveM servers using the ESX framework.

## Features

- Displays health and armor stats in PvP zones
- Customizable HUD settings
- Multiple PvP zones support

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start pvp_hud_system` to your server.cfg file.

## Usage

The PvP HUD will automatically display health and armor stats when players are within designated PvP zones.

## Configuration

Edit the `config.lua` file to customize the HUD position, size, color, and PvP zones.
